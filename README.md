# Excel Dashboard (Streamlit)

An interactive dashboard that turns any Excel file into charts, built with Python and Streamlit.

## Features
- Upload `.xlsx` / `.xls` and choose a sheet
- KPI cards (rows, columns, numeric columns)
- Data preview table
- Charts: Bar, Line, Scatter, Pie
- Aggregation: Sum, Average, Count or none
- Summary statistics table
- Download chart data as CSV

## Run
```bash
pip install streamlit pandas plotly openpyxl xlrd
python -m streamlit run Lab.py
```

## Tech
Python · Streamlit · Pandas · Plotly
